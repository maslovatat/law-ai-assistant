## Legal Case — платформа ведения юридических дел

Прототип сервиса, который помогает человеку пройти путь от описания проблемы до результата по делу, то есть собрать факты и документы, получить готовый проект претензии, отправить его и отслеживать ответ.
Проект делается в рамках Проектного практикума. Заказчик — профсоюз со штатной юридической службой.

## Зачем это нужно

Сейчас юристы профсоюза обрабатывают около 2 000 обращений в месяц. Значительная часть работы это типовые претензии. На каждое такое дело уходит время, хотя логика у них одинаковая.
Идея платформы в том, чтобы взять на себя всю рутину. Собрать информацию, проверить комплектность документов, подготовить черновик претензии. Юрист подключается только тогда, когда дело действительно сложное.

## Что уже работает в прототипе

Создание дела. Пользователь описывает ситуацию своими словами, система создаёт дело с уникальным номером.

Уточняющие вопросы. По сценарию претензия продавцу по дефекту товара система задаёт пять вопросов. Когда куплен товар, в чём дефект, кто продавец, были ли обращения, какой результат нужен.

Загрузка документов. Можно приложить чек, гарантийный талон, переписку. Файлы привязываются к делу, дубликаты отсекаются.

Автоматическая проверка. Система сама оценивает, типовое дело или сложное. Если находит признаки сложности, например упоминание суда или спора, передаёт дело юристу с указанием причины.

Журнал событий. Каждое действие фиксируется. Что произошло, когда и кто инициировал.

## Как устроен процесс

1. Пользователь описывает проблему.
2. Система создаёт дело и задаёт уточняющие вопросы.
3. Пользователь отвечает и загружает документы.
4. Система проверяет, достаточно ли данных и нет ли признаков сложности.
5. Если дело типовое, оно идёт по стандартному маршруту.
6. Если сложное, уходит юристу с пояснением причин.
7. Юрист проверяет и либо возвращает дело пользователю, либо ведёт его дальше.

## Технологии

Python.

Streamlit для интерфейса.

Git и GitHub для хранения кода.

Всё хранится в оперативной памяти на время сессии. База данных и подключение языковой модели это следующие шаги.

## Как запустить у себя

1. Склонировать репозиторий командой git clone https://github.com/maslovatat/law-ai-assistant.git

2. Перейти в папку проекта командой cd law-ai-assistant

3. Создать виртуальное окружение и установить Streamlit. Команды python -m venv .venv, затем .venv\Scripts\activate, затем pip install streamlit

4. Запустить командой streamlit run app.py

5. Открыть в браузере адрес http://localhost:8501
